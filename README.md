# Generic Prompt Engine
- The payload is in the form of a JSON dictionary that contains the model URL, token, tags(optional), and a dictionary of prompts.
- The payload is sent to my server, which connects to the LLM, and gives out the response to each prompt, in the form of a JSON dictionary.
